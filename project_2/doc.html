Project 2 Documentation

Proposal

For this project, I decided to use the Jikan (unofficial MyAnimeList) API to create a simple anime & manga catalog that allowed the user to save titles for later viewing. Below is the initial first sketch for the website layout.

Details

Much of this project was completed by Googling and referencing the Mozilla Web Docs and some of W3School's JavaScript tutorials. The majority of the code was written by myself, with much referencing from the HW Giphy Finder, previous web app labs, and the aforementioned tutorials. I used no AI or outside resources apart from these.

The main feature I want to highlight is the user's saved list, which is saved in local storage. Figuring out that I needed to parse information from an array to a string and vice versa was pretty difficult, and I'm proud for having solved it. However, I wasn't able to include the pagination for the search.
